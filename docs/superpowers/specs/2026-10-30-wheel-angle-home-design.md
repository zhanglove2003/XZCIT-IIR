# 手柄一键恢复四轮初始朝向：设计与交接

日期：2026-10-30。状态：用户同意功能方案，交由 DeepSeek 实现；本文不代表功能已经实现或上板验证。

补充需求：必须同时阅读 `2026-10-30-selfcheck-reference-flow-design.md`，其中定义自检异常标记、结束后 5 秒 USER 入口、手动对齐页和运行时反馈监测。开机接管/参考记录页面流程以补充设计为准。

## 1. 用户确认的行为

目标是恢复每个轮子的初始角度，沿最短路径转动；不是把累计行驶圈数倒回，也不是车身返回起点。例如某轮前进 3.5 圈，仅需转半圈。四轮独立判断方向、独立减速和停止。

采用一个 SELECT 键：停车并摆好四轮标记后长按 2000 ms 记录参考，短按触发归位。正好相差半圈时统一选择车辆后退方向。断电、复位后参考无效，必须重新记录，不写 Flash 保存角度。轮子转动会带动车身，不能保证车辆位置不变。现阶段只有单次/多圈人工标定，没有绝对角度传感器，不能承诺精密角度重复性。

现有 Ctrl 任务优先级高于 UI，目标周期 10 ms，读取约 3.27 ms，最近观察最大间隔 14 ms，失联停机期限 200 ms。驱动首次唤醒需在零 PWM 时拉高 SLP 后等待 10 ms。保持这些机制和普通摇杆映射不变。

## 3. 方案选择

推荐扩展现有 Ctrl 任务，增加一个纯 C 的角度归位状态机。此任务已持有电机写权限、手柄数据和 10 ms 循环，便于保持互斥。

不采用 UI 圈数作为反馈：`ui_main_page()` 累积五个 20 ms 采样后再刷新 OLED，诊断位置约 120 ms 更新一次且 int64 读取可能撕裂。不新增另一个直接写 PWM 的独立任务，避免与摇杆控制争用。

Ctrl 为归位单独保存四个 `wheel_feedback_t`，每循环只读硬件 CNT 并独立累加；UI 可继续自己的只读计数逻辑。多读者读 CNT 没有问题，双方都不能清零硬件定时器。Ctrl 中的前进归一化位置为 `raw_counts * forward_sign`，正 PWM 始终代表车辆前进。记录参考不改变原有累计净圈数显示，也不发 `wheel_feedback_zero_request`。

## 4. 参考与最短路径

初次进入 `boot_ui_ready` 时初始化四个 Ctrl 计数器，此时参考仍无效。每次取得有效新采样后更新位置，再处理按键。记录参考必须四轮停稳：四路命令为零、摇杆在死区，连续 300 ms 每轮每次 10 ms 采样变化不超过 `max(1, CPR/1000)`。使用真实时间而不是采样次数。

长按达到 2000 ms 且满足停稳条件时，同时保存四轮归一化位置为 `origin[4]`，设置 `reference_valid=1`，只触发一次。若不满足停稳条件，提示停车，不延后到任意时刻自动记录。按键释放前禁止手动驱动。

用 int64 做差和模运算。触发归位时，先为每轮固定一个最近的绝对目标，运动中不能每次重选另一圈：

```c
/* cpr > 0; x/origin are normalized int64 counts. */
int64_t phase = (x - origin) % (int64_t)cpr;
if (phase < 0) phase += cpr;
int64_t displacement = -phase;
if (phase * 2 > cpr) displacement += cpr;
/* Exact half -> negative displacement. */
int64_t target = x + displacement;
/* During the entire operation: error = target - current_x. */
```

例：CPR=1000，x-origin 为 3500 -> displacement=-500；3250 -> -250；3750 -> +250；-250 -> +250；1000 -> 0。奇数 CPR 不会出现整数计数的精确半圈，也应确保结果在最近半圈范围内。

## 5. 按键与控制权

每个有效 PS2 帧用 `(buttons & (1U << 0)) == 0` 判断 SELECT，使用按下/释放边沿与真实毫秒计时；有效变化连续稳定 30 ms 才接受。无效帧不推进稳定时长，不更新旧按键状态。失联后清空待处理手势，重连后先观察 SELECT 释放和摇杆居中，才重新接收操作，避免补发短按。

- SELECT 按下立刻置零四轮 PWM，优先于普通摇杆映射；等待释放以区分短按/长按。
- 30–1999 ms 的短按仅在释放时触发一次归位，且需要已有参考和摇杆居中。小于 30 ms 忽略。
- 长按只记录，不得在释放时再触发归位；长按失败也不能退化为短按。
- 无参考短按：不转，显示 `NO REF`。
- `HOMING` 期间忽略普通驱动输出；拨动任一摇杆超过中位 ±16、再次按 SELECT、进入标定模式、有效帧超时达 200 ms，立即取消归位并四轮 PWM=0。
- 取消/完成/故障后进入等待释放与居中状态，禁止在同一循环把刚取消归位的摇杆值变成非零手动输出。再次取得有效居中且 SELECT 释放持续 100 ms 后恢复手动模式。
- 失联、超时、卡轮或计数采样失效停止后让 SLP 睡眠；正常完成的处理也统一零 PWM 后睡眠。重新手动驱动沿用现有唤醒等待。

状态建议：`MANUAL`、`BUTTON_HELD`、`HOMING`、`WAIT_NEUTRAL`；参考有效性、最近结果（`RECORDED/DONE/CANCELLED/NO_REF/STALL/TIMEOUT/FEEDBACK`）分字段保存，避免把“未记录”变成无法手动驾驶的状态。只有 Ctrl 任务写电机。

## 6. 位置控制与初始调试参数

以下是待上板调试的起始值，不是已验证的机械性能：

| 参数 | 初值与行为 |
| --- | --- |
| 控制周期 | 10 ms，以真实经过时间计时 |
| 归位最大 PWM | 3360，即 ARR=16799 时约 20% |
| 归位最小 PWM | 1200，仅误差超容差且需要运动时使用；需实测静摩擦阈值 |
| 到位容差 | `max(1, CPR/200)`，即约 0.005 圈/1.8° 的编码器容差 |
| 比例输出 | `abs(error)*13440/CPR`，约四分之一圈误差达 PWM 上限，再限制到 1200…3360 |
| 停稳确认 | 零输出、误差在容差内且采样变化不超过 CPR/1000，持续 200 ms |
| 换向等待 | 先置零 PWM，等 40 ms，再改 DIR/输出；计时期间继续读手柄和编码器 |
| 无进展 | 非零命令实际生效累计 500 ms 内，到目标的最佳绝对误差未改善 CPR/1000，整次失败并停止四轮 |
| 总超时 | 从归位触发起 8000 ms，整次失败并停止四轮 |
| 采样异常 | 相邻归位计数采样间隔 >50 ms 时停止并使参考无效；不继续使用可能漏回绕的计数 |

误差在容差内立刻输出零，不施加最小 PWM。停稳确认中若漂出容差，重新纠偏并重置停稳计时。四轮都满足停稳条件才算 DONE；某轮先到位就先置零，该轮漂离后仍可重新纠偏。不是四轮用同一个 PWM 同时停止。

最小 PWM 不能用一次大力启动脉冲替代；不要自动增加上限。若发生来回纠偏、卡轮、转向相反或迟迟不到位，停机检查和调参。相邻采样变化仍必须小于 32768；16 位定时器丢整圈不能靠软件补猜。超时/重连配置等阻塞期间原有输出先置零，超过采样期限就使参考失效，之后需重新记录。

## 7. 屏幕与诊断

保留四轮 RPM 和累计净圈数含义。顶栏在 VDD 右侧显示短状态：`REF`、`SET`、`HOME`、`DONE`、`CANCEL`、`NO REF`、`STALL`、`TIMEOUT`、`ENC ERR`；新增 ASCII 文本先适配 128 像素宽度，不把现有 `line[24]` 写越界。状态文本优先于已有 CAL 标记，CAL 模式显示仍需明确。

UI 通过 `wheel_home_get_status()` 获得紧凑快照，禁止直接拼读 Ctrl 正在写的 int64。使用 FreeRTOS 短临界区复制快照，临界区内无 HAL、延时、I2C 或 OLED 操作。公开状态/目标/误差快照便于 SWD，但不要在调试脚本硬编码地址；每次构建从 ELF 符号读取。

## 8. 边界与验收

不自动设置开机参考，不在自检中触发本功能，不保存断电绝对位置，不修改校准参数/硬件计数器，不添加转向/横移功能。不承诺车身静止或精密机械角度。CPR 相对误差会影响机械朝向，已有约 1% 人工参考误差需在验收中如实记录。

验收必须包括纯数学与状态机测试、真实 Ctrl 任务集成测试、现有七组回归测试、固件构建、按键只读采集、单轮低速测试、四轮最终测试。先让轮子悬空且留出空间；上板自动动作前由现场用户确认准备就绪。记录原始计数、目标、结束误差、停止原因、实际标记位置，不能只看 OLED 的 DONE 宣称成功。
