# OLED 分层菜单、驾驶仪表盘与转向设计

日期：2026-10-31。对象：当前 STM32F407 麦轮车固件。交付用途：供 DeepSeek 或后续开发者实施。

状态：用户已同意“驾驶仪表盘 + 检查与标定子菜单”的结构。本文件细化交互和验收条件，等待书面方案审阅。此阶段只交付方案，不修改固件，不烧录，不下发电机动作。

## 1. 目标和范围

- 自检界面只显示电机、电池两类检查。四轮结果属于电机检查的明细。
- 品牌主页显示 `XZCIT-MFSC`，下一行显示较小的 `By Plucksnow`。
- R1 打开菜单或返回上一级，L1 确认。左摇杆在菜单中选择项目。
- 主菜单采用横向悬浮卡片。选中卡片轻跳。子菜单采用反白列表。
- 驾驶页面同时显示电压、行驶状态、四轮转速和累计净圈数，不再增加轮子数据页面。
- 左摇杆前后行驶，右摇杆左右转向，支持原地转和边走边转。
- 自检结果、重新自检、回到初始位、手动标定放在同一个功能组。
- 保留运动反馈检测、故障锁存、最短朝向归位和已标定的轮子映射。

首版不增加横移、里程导航、速度 PID 或电池百分比估算。屏幕提供卡片、列表、弹窗和滑动效果；固件使用固定页面与控件，不引入 HTML 解析器。界面文字全中文（2026-11-01 用户要求），驾驶仪表盘顶栏的行驶状态/参考/故障短代码（FWD、STOP、REF 等）除外——顶栏仅 12 像素高，放不下 16×16 汉字；品牌页副标题 `By Plucksnow` 为品牌名保留原文。

## 2. 已核对的当前代码

- 屏幕为单色 128 × 64。`oled_gfx` 已有像素、位图、矩形、6×12 ASCII 和 16×16 汉字绘制接口。
- 当前 `ui_main_page()` 直接允许驾驶，并自行累计另一份编码器位置。新页面必须取消“显示主页就允许开车”的关联，并统一使用 Ctrl 发布的数据。
- 当前普通驾驶只把 `drive_ctrl_map(ly)` 的结果送给四轮，没有左右转向混合。
- 当前开机自检由 UI 写电机，之后移交 Ctrl。运行中重新自检需要统一电机写入路径，不能直接从菜单重复调用旧开机函数。
- PS2 帧有四轴和低有效的 16 位按键。R1/L1 使用协议位 11/10，SELECT 使用位 0；正式测试动作前，须通过只读采集确认实际手柄对应关系。
- 当前“电池自检”调用 `ui_read_vdd_mv()`，读取内部 VREFINT，求出 MCU VDD。它不是电池电压。虽然 PB0 已配置 ADC1_IN8，本次检查没有确认实际电池分压比和电池规格。

## 3. 实现方式选择

推荐：小型页面状态机 + 页面绘制函数 + 固定数据快照。它适合现有屏幕和 FreeRTOS 架构，也方便逐项测试和增加子菜单。

另外两种方式不用于首版：

- 继续在 `boot_ui.c` 中增加嵌套循环：改动起点小，但会继续混合页面、手柄、自检和输出权限。
- 引入完整图形框架或网页解释器：可提供更多控件，但会增加依赖、内存和移植工作。当前两级菜单不需要这些成本。

## 4. 页面结构与启动流程

```text
上电 → 品牌主页（电机停止，手柄可连接）
          ├─ L1 / USER → 自检启动确认
          └─ R1 → 主菜单
                    ├─ 驾驶 → 驾驶仪表盘
                    └─ 检查与标定 → 子菜单
                                      ├─ 自检结果
                                      ├─ 重新自检 → 启动确认 → 自检进度 → 结果
                                      ├─ 回到初始位 → 归位进度与结果
                                      └─ 手动标定 → 长按 SELECT 记录参考
```

开机不自动转轮。进入驾驶仪表盘时，如果本次上电还没有通过电机自检，只能看数据，显示“请先自检”，不允许输出。

自检启动采用 5 秒倒计时确认（2026-11-01 按用户要求修改）：品牌主页按 USER 进入“即将转动四轮”确认页并自动开始 5 秒倒计时，倒计时归零自动启动自检；期间再按 USER 取消回品牌主页；L1 或摇杆右移为立即开始（跳过剩余等待）；摇杆左移取消。前置条件（手柄有效、四轴居中、供电保护允许）不满足时倒计时暂停并显示原因，条件满足后继续走完。启动前的释放与去抖规则保留：进入确认页的那次按键不算取消。

自检结束后所有输出归零，显示结果，并提供 5 秒手动标定入口：L1 或新按 USER 进入标定，R1 返回品牌主页，无操作则 5 秒后返回品牌主页。保留原 USER 窗口的释放、去抖和截止时间规则。结果可随时从子菜单重看。

超时、离开结果页、打开驾驶页均不清除异常，也不自动认定轮标记已经回到参考点。

## 5. 品牌页、卡片和列表

### 5.1 品牌主页

- 标题使用固定 10×16 ASCII 字模，只需本标题用到的字形。10 个字符共 100 像素，水平居中，起点 x=14、y=14。
- 副标题使用现有 6×12 字体。`By Plucksnow` 共 12 个字符、72 像素，起点 x=28、y=36。
- 底部 y=52 显示短操作提示或最高优先级异常。只显示一行，不能遮住标题。
- 不把现有 `text16` 当成大号英文接口：当前实现遇到 ASCII 只移动光标，不绘制字形。

### 5.2 主菜单

- 两张主卡片为“驾驶”和“检查标定”。子菜单页面标题可用完整名称“检查与标定”。
- 每张卡片约 92×32 像素，包含图标、短名称和选中边框。选中卡片居中于 x=18、y=20，相邻卡片在屏幕边缘露出一部分，表示可以继续移动；不是把两个完整卡片挤在同一屏。
- 左摇杆左右选择，不循环回绕。主菜单记住上次选中项。
- 选中卡片按 `0,-1,-2,-1,0` 像素偏移轻跳，周期 600 ms。未选卡片不跳。
- 切换时水平滑动约 120 ms。动画途中仍响应 R1、L1，不建立输入积压队列。

### 5.3 子菜单

- 16 像素高的标题，下面显示三行 16 像素高的列表。四个条目使用滚动窗口，底部画窄滚动标记。
- 左摇杆上下移动反白选中条。进入明细后，R1 回到原选中条目。
- “输出上限”页（2026-11-01 增加的第 5 项；同日上限扩至 90% 按用户要求）：显示当前驾驶 PWM 上限百分比与原始比较值；摇杆上下 ±5% 步进（范围 10%~90%，90%=15120=16800×90%，50%=8400 为历史默认），即时生效；仅约束驾驶混合输出（转向分量恒为上限的一半），自检、归位、手动标定的 PWM 不受影响；存 RAM，断电恢复默认 50%，不写 Flash。**>50% 的档位未经实车验证，上板时须从 60% 起逐档低速确认驱动与电机行为后方可使用。**
- 新功能以后以“菜单项 ID + 标题 + 图标 + 目标页面”加入表中，不复制整套按键逻辑。
- 首版只注册本方案列出的功能。保留扩展结构，不增加空菜单。

## 6. 驾驶仪表盘

驾驶页使用 5 行 6×12 字体，高度 60 像素。它是固定数据布局，不播放跳动或过场动画。

```text
B24.0V FWD     REF
A +120RPM  +001.50R
B +120RPM  +001.48R
C +118RPM  +001.51R
D +121RPM  +001.49R
```

以上数值仅为布局示例，不代表现场测量。

- 顶栏 y=0：电池区域 x=0..35，行驶状态 x=42..83，参考/故障状态 x=90..125。
- 四轮行的 y 分别为 12、24、36、48。轮名 x=0，RPM 区域 x=12..59，圈数区域 x=66..125。
- RPM 区域最多 8 个 ASCII 字符。圈数区域最多 10 个字符。超出范围显示 `OVF`，不挤入相邻列。无效采样显示 `--`。
- 圈数显示有符号累计净圈数，保留两位小数。倒转会减小数值。它不是累计行驶总路程。
- 记录初始朝向不清零累计圈数。圈数与“相对初始朝向的角度误差”是不同数据。
- 行驶状态使用 STOP、FWD、REV、LEFT、RIGHT、FWD-L、FWD-R、REV-L、REV-R 等短文本。它描述控制命令，不声称已测得整车速度或车体转角。
- 顶栏右侧按故障、失联、等待回中、无参考、参考有效的顺序显示状态。逐轮原因由“自检结果”查看；故障发生时驾驶页给出短提示并立即停机。
- R1 返回主菜单，并撤销驾驶输出。下一次进入驾驶须重新满足回中条件。

## 7. 手柄输入规则

| 输入 | 规则 |
| --- | --- |
| R1 | 品牌页打开主菜单；其他普通页面返回一级；运动动作中先取消并停止，再返回 |
| L1 | 确认选项；一次稳定按下只产生一个确认，不因长按连续进入多级页面 |
| 左摇杆左右 | 主菜单横向选择；驾驶页控制前后的是左摇杆 Y 轴，X 轴不控制车辆 |
| 左摇杆上下 | 子菜单选择 |
| 右摇杆左右 | 仅驾驶页控制转向 |
| SELECT 短按 | 驾驶页保留最短归位快捷入口；其他普通页面不触发运动 |
| SELECT 长按 2 秒 | 仅手动标定页记录初始位；驾驶页长按不重写参考 |
| USER | 品牌页打开自检确认；自检结果的 5 秒窗口内进入标定；手动标定页备用退出 |

按键使用有效帧及 30 ms 稳定判定。首次进入、重连或页面切换时，不接受此前已按住的确认键。R1 和 L1 同时按下时只接受返回/取消。SELECT 与确认键同时按下时不启动运动或记录。

菜单摇杆阈值：中心 128，偏移达到 48 才移动，回到偏移 24 以内才复位。按住 400 ms 后开始连移，之后每 180 ms 一步。横向卡片和纵向列表各自只用一个轴，避免斜推跳两项。

从品牌页、菜单、标定、动作结束或重连进入驾驶，必须四轴居中、R1/L1/SELECT 均释放，连续满足 100 ms。其他页面中的摇杆动作不产生驾驶指令。

R1 的稳定事件由 Ctrl 在本控制周期受理并撤销运动权限，不等待 OLED 完成刷新。归位或自检期间，摇杆越出驾驶死区也可取消动作。取消后禁止直接转入驾驶输出。

## 8. 前后与转向混合

定义前进为正，左转为正。V 来自左摇杆 Y 轴，T 来自右摇杆 X 轴。左右轴均以 128 为中心、死区为 16。正负两侧分别按有效行程归一化，保证两端对称到达设置上限。

首版保留前后最大 PWM 比较值 8400，转向分量上限设为 4200，作为低速初始参数。

```text
A（右前） = V + T
B（左前） = V - T
C（右后） = V + T
D（左后） = V - T

peak = max(abs(A), abs(B), abs(C), abs(D))
若 peak > 8400：四个值全部乘 8400 / peak
```

计算用至少 32 位有符号中间值，统一缩放后再交给现有正反转、换向等待和硬件限幅路径。

| 操作 | A / C | B / D |
| --- | --- | --- |
| 前推 | 正 | 正 |
| 后拉 | 负 | 负 |
| 原地左转 | 正 | 负 |
| 原地右转 | 负 | 正 |
| 前进左转 | 右侧更快 | 左侧更慢，极低前进量时可反转 |

右摇杆表示车体旋转方向。后退时右推仍请求车体右转，不采用汽车倒车方向盘的反向关系。此规则与“右摇杆控制旋转”的操作保持一致。

用户提供的运动学资料第 15 页图 5-4、第 16 页式 5-7 用于核对左右旋转符号。资料图轮序为左后、左前、右前、右后；不能直接套用成 A/B/C/D。首版使用 vy=0 的前进与旋转分量，PWM 混合不是速度闭环，不承诺给定转弯半径。实车滚子安装形式仍须现场核对。

## 9. 自检、电池与异常

### 9.1 电机

- 保留 A→B→C→D，每轮前转 500 ms、停 200 ms、后转 500 ms、停 200 ms，名义动作时间合计 5.6 秒。不为动画增加停留时间。
- 只验证有符号净反馈。保留现有至少 32 计数的判据和逐轮原因：OK、NO FB、FWD ERR、REV ERR、FB ERR、SKIP。
- 结果明细分两屏：电机四轮一屏，电池一屏，用左摇杆左右切换。它仍属于同一个结果模块，不新增主菜单。
- 自检运行期的反馈判据独立于普通驾驶的健康监测；不能让上一轮锁存故障阻止重新自检动作。取消或失败不清除旧故障，完整四轮通过才可清除电机锁存。
- 运行中继续使用实际施加 PWM 与编码器净变化判断缺反馈和反向反馈。保留现有 1200 最小检测 PWM、300 ms 启动宽限、300 ms 窗口和 64 计数阈值，现场验证后再调整。
- `NO FB` 表示没有运动反馈，不能当成已确认电机离线。异常时四轮停止，保留原因，等待处理后重新自检。

### 9.2 电池

- 实际电池使用 PB0/ADC1_IN8，换算为 `battery_mV = raw × VDD_mV × divider_num / (4095 × divider_den)`，中间乘法使用 64 位。
- 分压比例、电池额定规格、低压阈值、ADC 安全输入范围及实测校准均属于现场配置。先核对电路和万用表读数，再启用有效电池判断。
- 配置未确认时，驾驶页显示 `B--.-V`，结果显示“电池未配置”。不得显示百分比，不得把 VDD 显示成电池电压，也不得显示电池自检通过。
- 顶栏电池区域最多容纳 `B99.9V`。超出格式范围时显示 `B OVF`，详情页显示完整数值，不截掉高位。
- 电池状态与电机自检结果分别保存。电池未配置时允许继续验证菜单和原有外部供电驾驶，但总体自检不能显示“全部通过”。配置有效后的欠压或采样错误进入供电故障停机。
- MCU VDD 低压保护继续保留为内部运行保护，未通过时禁止运动，但不新增第三个自检清单项目。VDD 故障页仍可响应菜单返回，不能进入不可操作的无限等待。
- 电压服务是 ADC 的唯一使用者，低优先级周期采样，500 ms 更新电压快照。不在 10 ms Ctrl 路径中等待 ADC 转换。

## 10. 回到初始位与手动标定

回到初始位：L1 只提交请求。先停机，等待四轴居中、L1/R1/SELECT 释放连续 100 ms，再由 Ctrl 启动。进入页面的 L1 不能马上被归位取消逻辑误判成第二次操作。等待阶段 R1 可退出；不满足条件时一直显示原因，不转动。

有有效参考且无运动故障时，各轮独立按最近方向回到初始朝向，目标距离不超过半圈。整半圈沿用现有固定反向选择。页面显示 A/B/C/D 的等待、运动、到位或失败。归位是允许在专用进度页执行的受控动作，不属于菜单摇杆驾驶。

没有参考时只提示先标定。归位沿用现有 500 ms 无进展、8 秒总超时和采样异常取消规则。到位精度受手动 CPR 和机械误差影响，不能承诺精密角度。R1、其他新按键、摇杆动作、失联或反馈故障均取消归位并停止。

手动标定：进入时 PWM=0、驱动睡眠，Ctrl 持续采样和读取手柄。用户手动对齐四轮标记；四轮连续静止 300 ms、手柄有效、四轴居中后，新长按 SELECT 2 秒提交记录。记录瞬间再次核对前置条件，四轮一起捕获，收到 Ctrl 成功应答后才能显示“已记录”。

调整、坏帧或摇杆离开中心会取消本次长按计时。进入页面时已按住 SELECT，须释放后重按。长按后的释放不能触发短按归位。R1/USER 退出不记录；成功后停留在本页，R1 返回，不自动进入驾驶。

原有驾驶页长按 SELECT 记录入口收敛到手动标定页，避免驾驶时误改参考。标定不会解除电机故障。重启后参考无效；重新自检期间保留编码器连续计数但不自动重记参考，也不宣称轮标记已经回到参考朝向。

## 11. 控制与显示边界

1. Ctrl 为 PS2 输入、编码器累计、页面逻辑状态和电机动作的唯一写入者。UI 为 OLED 缓冲和刷新操作的唯一写入者。
2. 上电初始化与运行自检都通过 Ctrl 的单一电机应用出口。UI 不调用 PWM、DIR、SLP 写入。现有 UI/CTRL 双归属逐步迁移为单归属，不能简单删锁后保留旧写入代码。
3. Ctrl 每 10 ms 轮询、采样、推进输入事件与动作、仲裁、施加输出、发布快照。通过 `osDelayUntil` 保持周期；无 OLED、阻塞串口、长延时或 ADC 等待。
4. 页面状态和运动许可分开。最高优先级为系统/供电异常与取消，其次专用自检或归位，再次满足条件的驾驶，其余状态零输出。重新自检只放行其自身受限动作，不能放行驾驶。
5. 页面打开不等于驾驶许可；处于驾驶页也可能因自检未完成、故障或等待回中而零输出。归位/自检有显式忙状态，不能与普通驾驶叠加。
6. UI 读取完整快照：页面 ID、焦点、动作进度、按键状态、电池有效性、轮速、64 位累计计数、参考状态及逐轮故障。采用经验证的 RTOS 消息/受保护快照，不能用 `volatile` 假定多字段或 64 位数据原子一致。
7. 累计圈数和归位使用同一份 Ctrl 编码器累计数据。UI 不再独立读取 CNT，不随切页重置计数，不重新设置硬件编码器 CNT。
8. UI 逻辑与动画约 20 ms 推进一次；实际全屏刷新最多 20 Hz。驾驶数据 10 Hz，电压 2 Hz。若软时序刷新占用过长，则降低绘制刷新频率，Ctrl 周期不随之降低。
9. 坏帧当轮不沿用旧驾驶指令。失联 200 ms 进入重连流程，恢复后释放按键并回中 100 ms。归位或自检出现无效手柄帧即停止并取消；重连不自动续跑。
10. 所有时间使用真实毫秒与回绕安全差值。动画用查表位移，不在 UI 中用循环等待或 `HAL_Delay`。

## 13. 测试与验收

主机测试至少覆盖：

- R1 打开/返回、L1 单次确认、同时按键优先级、页面切换时按住键、坏帧、重连、摇杆阈值与连移、毫秒回绕。
- 品牌页、主菜单、子菜单、结果页、手动标定均不产生驾驶输出。进入驾驶时推着杆不能出力；回中 100 ms 后才放行。
- 前进、后退、原地左右转、边走边转、满幅混合统一限幅、死区、正负端点、停止和已有换向等待。
- 打开菜单后下一控制周期撤销输出，不等待完整 OLED 刷新；没有动画路径可以向电机发指令。
- A/B/C/D 的反馈映射、符号、CPR、累计负圈数、两位小数、显示越界和切页后计数连续。
- 真实 UI + Ctrl + 自检服务一起运行：每轮两个 500 ms 运动段，零输出间隔正确；正常、缺反馈、反向、跳过、取消均给出对应结果。
- 上一轮故障锁存时允许重新自检，但重新自检失败或取消不能清故障；全通过后还须经过驾驶回中门槛。
- 菜单 L1 发起归位后不会被同次 L1 自己取消；等释放后才运行。无参考不转、短按快捷入口、半圈边界、取消、超时与四轮分别到位。
- 手动标定连续静止 300 ms、新长按 2 秒、移动中拒绝、断连拒绝、第一次合法请求即可成功、失败应答不显示成功、长按释放不触发归位。
- 电池未配置/有效/欠压/采样错误、VDD 故障、ADC 通道切换正确；3.3 V 不能出现在电池读数中。
- 128×64 缓冲输出检查：标题/副标题字号不同，四轮数据同页无重叠，选中框反白，卡片跳动不出界，长数值不挤列，所有中文有字形。

回归命令包括 `bash tools/test_motion.sh` 和 `bash tools/test_boot_ctrl_integration.sh`。新页面模型、双轴混合、渲染、电源服务和自检服务各有对应主机测试；内存/越界测试使用 ASan/UBSan。用固定 ARM 工具链构建，记录版本、告警、固件大小和 SHA-256，避免把不同编译器的产物差异当成逻辑变化。

上板验收按以下顺序进行，须另行安排现场操作：

1. 电机动力关闭，只读核对 R1/L1/SELECT 和摇杆轴。检查主页、菜单、字体和页面返回。
2. 核对电池接线、分压、规格与万用表读数。未完成前保留未配置状态。
3. 确保轮子可安全转动，低速确认前进、后退、原地左右转和 B 轮方向。保留现有硬件极性，不按猜测反转 B。
4. 用户配合确认菜单停机、回中恢复、断连停机、自检异常与重跑、手动标定、最近方向归位。
5. 测量手柄有效采样至输出更新的时间。软件目标为正常运行时在一个 10 ms 控制周期内更新，唤醒和反向沿用现有等待；机械启动时间另行记录，不用屏幕刷新时间代替。
